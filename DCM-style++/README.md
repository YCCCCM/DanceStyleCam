# DCM-style++

This directory is generated by
`python tools/data/prepare_dcm_style_pp.py --config configs/data/dcm_style_pp.yaml`.
It stores one memory-mappable NPY file per source sequence and feature type,
plus fixed clip-level music35 NPY files. It does not contain physical Train/Test
copies, audio copies, or pickle caches.

Expected generated layout:

```text
DCM-style++/
|-- manifest.json
|-- motion180/
|-- camera20/
|-- music35/
|   |-- manifest.json
|   `-- clips/
|-- keyframe_mask/
`-- bone_mask60/
```

`manifest.json` describes numeric arrays only. Split and style annotations stay
in `DCM_data`, so editing them never rebuilds these arrays.

`music35/clips/` contains one fixed 35D feature array per virtual clip. Create
or extend it with `python tools/data/prepare_music_features.py --config <data-config>`.
The tool imports existing DCM++ `aist_feats_long` features when supplied with
`--source`; it extracts only missing clips and then training and inference read
these NPY files without loading audio.
