# DCM-style++

This directory is generated by
`python tools/data/prepare_dcm_style_pp.py --config configs/data/dcm_style_pp.yaml`.
It stores one memory-mappable NPY file per source sequence and feature type. It
does not contain physical Train/Test copies, audio copies, or pickle caches.

Expected generated layout:

```text
DCM-style++/
|-- manifest.json
|-- motion180/
|-- camera20/
|-- music35/
|-- keyframe_mask/
`-- bone_mask60/
```

`manifest.json` describes numeric arrays only. Split and style annotations stay
in `DCM_data`, so editing them never rebuilds these arrays.

The stored `music35` arrays describe complete aligned sequences. By default,
training and inference use `dataset.music_feature_mode: legacy_clip`: the
legacy clip-local music feature is computed from `DCM_data` audio in memory and
cached only for the current process. This preserves the old DCM++ clip-boundary
behavior while keeping this directory independent of the split JSON files.
